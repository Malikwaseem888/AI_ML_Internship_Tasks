# AI_ML_Internship_Tasks

#  Iris Dataset Exploration Project

##  Task Objective
The objective of this task is to explore and visualize the Iris dataset 
to understand patterns, relationships, and distributions among different flower species. 
This project focuses on data loading, inspection, descriptive statistics, 
and visualization using Python libraries.

---

## Dataset Used
- Dataset Name: Iris Dataset
- Source: Seaborn built-in dataset
- Total Samples: 150
- Total Features: 4 numerical features + 1 target column

### Features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species (Setosa, Versicolor, Virginica)

---

##  Models Applied
No machine learning model was applied in this task.
This task focuses only on:
- Data exploration (EDA)
- Data visualization
- Understanding feature relationships

---

##  Key Results and Findings
- The Setosa species is clearly separable from the other two species.
- Petal Length and Petal Width show strong correlation.
- Some overlap exists between Versicolor and Virginica.
- No missing values were found in the dataset.
- Visualizations helped in understanding feature importance.

---

##  Tools & Libraries Used
- Python
- Pandas
- Seaborn
- Matplotlib
- Jupyter Notebook

---

##  Conclusion
The Iris dataset is clean and well-structured. 
Data visualization provides clear insight into species separation 
and feature relationships, making it suitable for future classification tasks.
